# Do You Love Me – Fun Button Game (PC Version)

A fun and interactive browser-based mini project where users are asked **"Do you love me?"** — clicking "Yes" displays a sweet "I love you too" message, while the tricky "No" button keeps jumping to random positions, making it nearly impossible to click.

This is the **PC version**, specifically designed for larger screens with precise alignment and spacing. Built using **HTML, CSS, and JavaScript**, the project offers a lighthearted, romantic interaction that is both responsive and playful.

Perfect for showcasing frontend skills in a fun and engaging way!
